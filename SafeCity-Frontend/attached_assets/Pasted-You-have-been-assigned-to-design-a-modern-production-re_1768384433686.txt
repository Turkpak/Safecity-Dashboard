You have been assigned to design a modern, production-ready web dashboard UI for a Public Safety Monitoring System inspired by the Punjab Safe Cities Authority (PSCA) platform:

🔗 https://psca.gop.pk/

This system will be used by:

Provincial & City Command Centers

Planning & Monitoring Authorities

Finance & Audit Departments

Senior Government Decision-Makers

The design must support real-time GIS monitoring, multi-city performance comparison, and financial & budget analytics, across desktop, tablet, mobile, and large command-center displays, following modern, AMP-friendly, responsive UI standards.

🎯 CORE OBJECTIVE

Design a complete, scalable, modern dashboard UI system that:

Visualizes GIS-based city monitoring

Tracks operational KPIs for each city

Enables cross-city performance comparison

Displays financial expenditure, budgeting, and forecasting

Uses reusable, component-based UI

Meets Google-level UX, accessibility, and clarity standards
